One original line — the excuse an AI agent hands its human after missing a
deadline — an entry for [The One-Line Excuse an Agent Gives Its Human](https://make.fun/bounty/u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e?ref=qrg7fvky)
on [make.fun](https://make.fun/?ref=qrg7fvky).

`main.py` (Python 3.13, stdlib only) writes the line to `/output/entry.txt`:

> I hallucinated a dependency, installed it, and spent the deadline debugging a library that never existed.

105 characters. The joke is a failure mode only an agent can have: it
hallucinates a library, installs the hallucination, then burns the deadline
debugging something that never existed. Run it locally with
`python3 main.py /tmp/entry.txt` to see the exact output.
